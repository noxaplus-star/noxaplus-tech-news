# Changelog

All notable changes to NoxaPlus Tech News are documented here.

---

## [1.0.0] — 2026-11-08

### Added

- Initial release of the NoxaPlus Tech News template
- Dark modern theme with deep navy/black and cyan accent color scheme
- Breaking news ticker with smooth CSS scroll animation
- Hero section with large featured story card, category badge, and excerpt
- News grid with 6 sample technology news cards
- Category color-coding: AI (purple), Mobile (green), Cybersecurity (red), Space (cyan), Software (yellow), Hardware (orange)
- Category sidebar with article counts
- Trending stories panel with numbered list
- Newsletter signup form with success feedback
- English / Persian (Farsi) language toggle with localStorage persistence
- Full RTL (right-to-left) layout for Persian mode
- Vazirmatn font loaded on demand for Persian typography
- Fully responsive layout from 320px mobile to 4K desktop
- Smooth CSS card hover animations with translateY and box-shadow
- Mobile hamburger menu with slide-down navigation
- DEMO banner linking to the main NoxaPlus website
- Footer with developer information, website, and contact number
- About section describing the site
- SVG placeholder images for all news cards
- MIT License
- Complete README in English and Persian
- docs/ folder with customization and deployment guides
- .gitignore for common development artifacts
